# Changelog

## 0.3.0
- `commit-message` rejects vague summaries ("update code", "fix stuff") and asks for concrete wording.
- Notes in the commit body whether tests were added or changed.

## 0.2.0
- `commit-message` now follows project conventions from `CLAUDE.md` / `CONTRIBUTING.md`.
- Matches the language of recent commits.
- Adds a `Refs:` footer when the branch name contains a ticket ID.

## 0.1.0
- Initial release: `commit-message` skill.
